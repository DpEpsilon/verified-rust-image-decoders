# Sources and evidence boundary — draft 2

`READ` means a complete local file or the relevant source code was actually inspected. `RECALLED` means a format assertion was **not** established by reading a primary specification. `DECISION` marks this decoder's policy. Both local gdk-pixbuf baselines were read in full: `/__modal/volumes/vo-Iyh3VLkOB7cEHrIp2RkTs7/projects/spec/gdk-pixbuf/gdk-pixbuf/io-bmp.c` and `io-ico.c`. They are implementation evidence, not normative authorities. Attempts to fetch the Microsoft pages below with WebFetch returned `ECONNRESET`; search snippets supplied some content, but no full primary-format document was read. Accordingly **no Microsoft claim is labelled READ**. These links identify the primary documents for a later evidence pass, not verified primary-source support for this draft.

The 200 revised fixtures have manually authored expected errors/pixel runs; the fixture-revision script is separate from `check_vectors.py`, which reparses every byte. `python3 -I spec/check_vectors.py` passes **200/200**. The independent reviewer reported agreement between an independently written oracle and **all 186 draft-one vectors**, plus pixel-identical results for 82 decodable corpus files; the **revised 200 vectors have not yet undergone another independent reviewer oracle pass**. The maximum-output fixture uses 266,290 input bytes and 67,108,864 output bytes, painting red rather than returning the black initial RLE fill. The full-input fixtures are settled by the length guard without expansion. No digest or freeze exists.

Corpus: [Pillow repository](https://github.com/python-pillow/Pillow), commit `aa60851e1f0f00a82560a553cbad4429d9233b86`, 84 regular `Tests/images` BMP/ICO/CUR files, each <=1 MiB, total 1,365,291 bytes; sparse shallow clone, files copied without Git history. Repository `LICENSE` states MIT-CMU terms, but some images may carry independent rights; **local testing only, do not redistribute**. `tools/run_corpus.py` chooses the first DIB image. It compensates for two single-entry CUR fixtures whose directory says eight bytes although their complete DIB runs from offset to EOF; that shim workaround does not change the future container specification or permit slack inside a correctly delimited ICO entry.
