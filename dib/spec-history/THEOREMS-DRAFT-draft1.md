# DIB core theorem manifest — DRAFT

This manifest targets `spec/SPEC.md` DIB-CORE-SPEC 1.0 (R1–R18), not a frozen contract. Use one ordinary Rust/Verus decoder with borrowed `&[u8]`, an enum `Mode` and one owned RGBA `Vec<u8>`. No executable code, test oracle or baseline C function may be imported into the mathematical models. The proof must hold for 32-bit and 64-bit Rust slice domains (`|b|<=isize::MAX` on each target), not merely a host-64-bit build. The deliverable implementer states verifier/compiler/library versions and never uses `assume`, `admit`, `external_body`, trusted FFI, unsafe, false preconditions or ghost claims disconnected from concrete calls. Allocation failure and compiler/verifier unsoundness are outside the guarantee.

## Total mathematical models

`MH(b,mode)` independently evaluates the **entire ordered R1–R7 prefix**, using mathematical integers and conditional guarded LE reads, and returns `Err(e)` or the full successful record `(mode,s,H,w,h,stored_height,depth,compression,declared_image,count,palette_slice,mask_tuple,pixel_start,N,stride)`; no input substring is read before availability is proved. `MP(b,mode)` propagates `MH` errors, creates a mathematical `RGBA^N` sequence with R8 initialization, applies R9 raw/bitfield conversion or the R10–R11 RLE transition, R12 image length/AND/suffix checks, and returns the **exact** `Ok(w,h,rgba)` or first `Err(e)`. These are total over representable slices. The `Mode` enum admits exactly three values; forged records are not a public API route.

`MR(b,H,p0,x0,y0,out0)` is the **total RLE stream model** for a successful `MH` record `H` with its depth, palette bytes/count, output dimensions, top-first orientation and image-length metadata; `b` is the original entire immutable input slice, `p0` is the checked absolute pixel cursor, `(x0,y0)` a reachable bottom-up RLE state, and `out0` is the full prefilled mathematical RGBA sequence. For reachable calls it returns `Ok(p',x',y',out')` on EOB or `Err(e,p',x',y',out')` for the first packet error, with ghost cursor/state/output observed **at that check**, including partially painted earlier commands. It checks two-byte command presence, bounds, complete delta/absolute payload, then individual index in R10–R11 order. For other records/offsets return an internal `OutsideDomain` marker, **not a 27th API error**. `MP` may invoke this mathematical `MR`, but the concrete RLE helper must be compared at the same original slice and reachable initial state. `MH`/`MR` must never call the executable parser.

`MA(b,H,out,p)` is a total AND-mask model: on reachable successful XOR state it requires exactly `stride(w,1)*h` bytes, maps bottom-up mask rows to top-first alpha bytes and returns `(out',p')` or `TruncatedAndMask`; on other states it returns `OutsideDomain`. `Conv(H,word_or_index)` is a separate mathematical colour function (including mask scaling, BI_RGB 555, ICO BGRA and indexed BGR); it signals an invalid index at the first selected pixel. `Accepted(b,mode)` means `MP(b,mode)=Ok(...)`. All model errors are exactly R15's 26 names.

## Compact-vector protocol and non-vacuity

Pass every **186** `spec/VECTORS.json` input with a separate implementation, then prove **model-versus-expected** for each fixture rather than assuming oracle output. Exactly **183** small inputs (all except the two whole-input repeat cases and one large output repeat case) can be expanded concretely for the verifier; L1–L3 cover the three large cases. Named witnesses, each requiring an explicit reported model agreement, include:

- Headers and precedence: `empty`, `file-short`, `file-bad-magic`, `file-size-mismatch`, `file-offset-before-palette`, `header-12-BareDib`, `header-16-BareDib`, `header-64-BareDib`, `header-108-BareDib`, `header-124-BareDib`, `planes-before-dimensions`, `dimensions-before-depth`, `compression-before-combo`, `combo-before-orientation`, `orientation-before-color-count`, `color-count-before-output`, `output-before-palette`.
- Palettes and masks: `indexed-1-header-12`, `indexed-4-header-16`, `indexed-8-header-40`, `palette-short-one-8`, `palette-short-invalid-index-4`, `palette-truncated-8`, `masks-40-16`, `masks-56-32`, `masks-overlap`, `masks-hole`, `masks-zero`, `masks-short-before-invalid`.
- Pixels and RLE: `bi-rgb-16-4404`, `bi-rgb-32-11223300`, `bottom-up-two-rows`, `top-down-two-rows`, `row-padding-24-two-pixels`, `rle4-encoded`, `rle8-eol`, `rle8-delta`, `rle8-absolute-odd`, `rle4-absolute-even`, `rle8-absolute-row-overrun-precedes-short`, `rle8-absolute-trunc-before-index`, `rle8-early-eob-trailing`, `rle4-missing-end`.
- ICO and limits: `ico-1-and-1`, `ico-1-custom-palette`, `ico-24-and-0`, `ico-32-and-1`, `ico-alpha-and-zeroes`, `ico-mask-msb-and-padding`, `ico-truncated-and`, `ico-odd-height`, `input-exact-64m`, `input-over-64m`, `output-exact-64m-rle8`.

Write `Q=bytes(0x80,0x00)^64 + bytes(0,0)` (128 decoded black pixels per encoded pair, 8192 pixels then EOL), `H=the literal first 44 fixture bytes` (40-byte INFO header with width 8192, height 2048, depth 8, compression RLE8, used=1; four-byte black palette), `E=bytes(0,1)`. Define `Q^k` as byte-string concatenation and `black^m` as repetition of RGBA bytes `000000ff`. Prove these symbolic lemmas instead of evaluating 16,777,216 pixel writes in Verus:

- L1. For any `|b|>67,108,864`, `MP(b,mode)=Err(FileTooLarge)` in every mode; instantiate the one-zero-byte `input-over-64m` repetition of 67,108,865.
- L2. For `b=0^67,108,864` in `BareDib`, `MP(b,mode)=Err(UnsupportedHeaderSize)` because the size word is zero and input length is **equal** to the cap. Instantiate `input-exact-64m`, killing an incorrect `>=` input guard.
- L3. Establish by induction on `k∈[0,2048]` that after `H+Q^k` the RLE cursor has advanced `130*k` bytes, `(x,y)=(0,k)`, and the first `8192*k` source pixels are black; every packet passes palette/bounds checks. The final EOB consumes two bytes even when `y=h`. Instantiate `output-exact-64m-rle8`: `|H+Q^2048+E|=44+266,240+2=266,286`; `N=8192*2048=16,777,216`; `MP(...)=Ok(8192,2048,black^16,777,216)` with `|rgba|=67,108,864`. Factor a 64-packet row lemma from the general packet repetition lemma; prove scanline mapping separately. Symbolic sequences are model facts, not a 64 MiB verifier allocation.

## Deliberate proof-sensitivity mutations

Run each change on an isolated copy and preserve **failed verifier diagnostics** with all T1–T13 enabled. A failing fixture alone does not count. Each bullet identifies a fixture or symbolic boundary and the theorem that must reject the mutation; if an invariant accidentally reconstructs a removed check, inject an actual wrong read/write instead.

1. Change input cap `>` to `>=`: `input-exact-64m`, L2, T2/T9/T10 fail.
2. Swap planes and dimensions checks: `planes-before-dimensions`, T2/T10 fail.
3. Parse OS/2 16-byte dimensions at CORE offsets: `header-16-BareDib`, T2/T9 fail.
4. Ignore `biClrUsed` and always read the maximum palette: `palette-short-one-8`, T2/T9 fail.
5. Use a three-byte stride for INFO palette: `indexed-4-header-16`, T4/T9 fail.
6. Remove index bound before borrowed palette access: `palette-short-invalid-index-4`, T1/T4 fail.
7. Permit overlapping masks: `masks-overlap`, T2/T9 fail.
8. Replace rounded mask scaling with five-bit replication: `bi-rgb-16-630c` has each channel `c=3`, so rounded scaling gives 25 and replication gives 24; T4/T9 fail.
9. Treat BI_RGB32 alpha byte as real alpha in BmpFile/BareDib: `bi-rgb-32-11223300`, T4/T9 fail.
10. Ignore ICO AND when depth is 32: `ico-32-and-1`, T8/T9 fail.
11. Reverse vertical orientation: `bottom-up-two-rows`, T5/T9 fail.
12. Read only unpadded row bytes: `row-padding-24-two-pixels`, T5/T6/T9 fail.
13. Allow RLE runs to cross rows: `rle8-absolute-row-overrun-precedes-short`, T7/T10 fail.
14. Check absolute input completeness before bounds: same overrun-precedes-short witness, T7/T10 fail.
15. Check an absolute palette index before whole padded packet availability: `rle8-absolute-trunc-before-index`, T7/T10 fail.
16. Omit EOB requirement: `rle4-missing-end`, T7/T9 fail.
17. Omit full-mask guard before a mask read: `ico-truncated-and`, T1/T8 fail.
18. Compute `N=w*h` using `u16` or reserve the output before its cap test: `output-exact-64m-rle8` is a runtime witness for `u16`; T1/T2/T3 fail by a verified overflow or oversized allocation path.
19. Re-scan the entire remaining byte slice on every RLE command (e.g. count trailing zeros each time) without changing output: T12 fails on `Q^k` for sufficiently large k, even if every functional fixture passes.
20. Allocate a second full-size scratch RGBA buffer: T3 fails for `output-exact-64m-rle8` despite identical output.
21. Accept arbitrary suffix bytes: `rle8-early-eob-trailing`, T9/T10 fail.
22. Ignore alpha in a 32-bit ICO pixel whose AND bit is zero: `ico-32-and-0`, T4/T9 fail.
