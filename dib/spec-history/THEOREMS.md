# DIB core theorem manifest (frozen)

This manifest targets `spec/SPEC.md` DIB-CORE-SPEC 1.0 (R1–R18), not a frozen contract. Use one ordinary Rust/Verus decoder with borrowed `&[u8]`, an enum `Mode` and one owned RGBA `Vec<u8>`. No executable code, test oracle or baseline C function may be imported into the mathematical models. The proof must hold for 32-bit and 64-bit Rust slice domains (`|b|<=isize::MAX` on each target), not merely a host-64-bit build. The deliverable implementer states verifier/compiler/library versions and never uses `assume`, `admit`, `external_body`, trusted FFI, unsafe, false preconditions or ghost claims disconnected from concrete calls. Allocation failure and compiler/verifier unsoundness are outside the guarantee.

## Total mathematical models

`MH(b,mode)` independently evaluates the **entire ordered R1–R7 prefix**, using mathematical integers and conditional guarded LE reads, and returns `Err(e)` or the full successful record `(mode,s,H,w,h,stored_height,depth,compression,declared_image,count,palette_slice,mask_tuple,pixel_start,N,stride)`; no input substring is read before availability is proved. `MP(b,mode)` propagates `MH` errors, creates a mathematical `RGBA^N` sequence with R8 initialization, applies R9 raw/bitfield conversion or the R10–R11 RLE transition, R12 image length/AND/suffix checks, and returns the **exact** `Ok(w,h,rgba)` or first `Err(e)`. These are total over representable slices. The `Mode` enum admits exactly three values; forged records are not a public API route.

`MR(b,H,p0,x0,y0,out0)` is the **total RLE stream model** for a successful `MH` record `H` with its depth, palette bytes/count, output dimensions, top-first orientation and image-length metadata; `b` is the original entire immutable input slice, `p0` is the checked absolute pixel cursor, `(x0,y0)` a reachable bottom-up RLE state, and `out0` is the full prefilled mathematical RGBA sequence. For reachable calls it returns `Ok(p',x',y',out')` on EOB or `Err(e,p',x',y')` for the first packet error; a failing helper exposes the exact error and ghost cursor/coordinates, **not** partially painted output. It checks two-byte command presence, bounds, complete delta/absolute payload, then individual index in R10–R11 order. For other records/offsets return an internal `OutsideDomain` marker, **not a 27th API error**. `MP` may invoke this mathematical `MR`, but the concrete RLE helper must be compared at the same original slice and reachable initial state. `MH`/`MR` must never call the executable parser.

`MA(b,H,out,p)` is a total AND-mask model: on reachable complete XOR state it computes `A=stride(w,1)*h`, checks the R12 permitted `biSizeImage` values **before** mask availability, requires `A` bytes, then scans all XOR alpha values once at 32 bpp and selects either the XOR plane or the bottom-up AND fallback for the entire image. It returns `(out',p')` or the exact `InvalidImageSize`/`TruncatedAndMask` error; on other states it returns `OutsideDomain`. `Conv(H,word_or_index)` is a separate mathematical colour function (including mask scaling, BI_RGB 555, ICO BGRA and indexed BGR); it signals an invalid index at the first selected pixel. `Accepted(b,mode)` means `MP(b,mode)=Ok(...)`. All model errors are exactly R15's 26 names.

## Quantified obligations

| ID | The claim to verify on **all** representable inputs unless a stated reachable-state precondition applies |
| --- | --- |
| T1 safety | `forall b,mode: Safe(decode(b,mode))`: no panic, OOB read/write, unchecked integer overflow or narrowing, or unbounded allocation request, assuming allocation succeeds and an ordinary stack. Do not assume valid input or length below cap. Absence of I/O/recursion is a code-review condition, not a Verus memory property. |
| T2 exact header | `forall b,mode: concrete_header_prefix(b,mode)=MH(b,mode)` as complete successful record or exact first error, including file-size/offset checks, OS/2 12 **versus 16** layout, bitfields, palette counts, caps and two `InvalidPixelOffset` check sites. Compute `palette_length=table_count*palette_stride` and `p+palette_length` in `u64` before comparing or narrowing to `usize`; `biClrUsed=0x40000000` must not wrap on 32-bit targets. Success invariants arise from executable guards, not axioms. |
| T3 allocation-call bound | Before an allocating call prove the concrete header has `1<=w,h<=8192`, `N=w*h<=16,777,216`, `4N<=67,108,864`. On a successful path invoke **exactly one** output allocation with requested size exactly `4N`; header-error paths invoke none; every other decoder path invokes no additional allocation, including inside loops. State the allocation-call count as a ghost counter incremented at the call site, with `0<=count<=1`; do not claim Verus proves physical allocator overhead or stack size. A source-level review excludes clones, growing vectors, formatting, recursion, I/O and input-sized stack locals. |
| T4 conversion | For all reachable `MH` records and guarded samples/indices, concrete `conv` equals `Conv` byte for byte: BGR order, palette stride 3/4, 555 rounding, 16/32 bitfield scaling with absent alpha 255, BI_RGB32 alpha split by mode, and 32-bit ICO XOR alpha zero preservation. Each palette read stays in the validated borrowed palette range. |
| T5 orientation and row arithmetic | For valid `w,h,depth`, `stride=4*ceil(w*depth/32)` is four-byte aligned, covers the last raw sample and is <=32,768. Each raw sample write is within `4N`; bottom-up/top-down map is a bijection `[0,N)→[0,N)`. The 1-bpp AND stride and MSB-first offset stay inside the checked mask. Distinct `(x,r)` map to distinct pixel cells. |
| T6 exact raw | For every reachable `MH` with RGB or BITFIELDS, concrete raw helper equals the mathematical raw transition on success (cursor plus all RGBA bytes) or the exact first error and ghost cursor on failure, including first short row, earlier invalid palette index and padding. No partial output equality is required on error. |
| T7 exact RLE | Factor a bounded two-byte command/absolute-packet parser and a <=255-pixel painter into named verified lemmas; for each reachable `MH` and every finite suffix, concrete helper equals `MR` on exact error plus ghost `(cursor,x,y)`, or success `(cursor,x,y,out)`. EOB can precede full image, EOL can set y=h, deltas cannot escape, runs cannot cross rows, absolute byte padding is consumed, and precedence is exact. |
| T8 exact ICO AND | For every reachable complete XOR state in `IcoEntryDib`, concrete image-size/mask helper equals `MA`: `biSizeImage∈{0,X,X+A}` before mask availability; when any 32-bpp explicit XOR alpha is nonzero ignore AND, otherwise apply AND as an opaque/transparent fallback; when BITFIELDS has no alpha mask, AND bit one vetoes its implicit opaque alpha. Preserve 16-bpp explicit alpha under a clear AND bit. No container-directory premise. |
| T9 integrated correctness | `forall b,mode: decode(b,mode)=MP(b,mode)` as **exact Result including every output byte**. Connect concrete `decode` to T2/T4–T8 on the **same slice**, with no independently forged header, palette or mode. |
| T10 error precedence | For every R15 error `e`, `decode(b,mode)=Err(e) iff MP(b,mode)=Err(e)`; prove R14 operational ordering, including RLE bounds before absolute completeness, absolute completeness before index and pixel before image-size/AND/suffix. No partial image or second error escapes. |
| T11 termination | Every call terminates: fixed-size header parsing, finite row/pixel loops, RLE command cursor increases by >=2 per successful iteration (including zero-delta and EOL), and EOB returns. Reject before parsing an incomplete command. No recursive walk or repeated retry of a zero-progress packet. |
| T12 linear work | Instrument **actual concrete loop bodies** by `ghost steps: nat` with R18's accounting, including work of any library fill. Let `N=0` when `MH=Err`, otherwise its checked `w*h`. `forall b,mode: steps(decode(b,mode)) <= 16*(|b|+N)`. Maintain `0<=cursor<=|b|`, RLE `x<=w,y<=h`, monotonic `(y,x)` under EOL/delta and paints, `painted<=N`, `commands<=floor((|b|-pixel_start)/2)` for entered complete commands, `raw_pixels<=N`, `mask_pixels<=N`, `alpha_scan_pixels<=N` and per-phase counter budgets. State a phase-specific potential such as `steps<=8*cursor+8*N`, discharging fixed header work against bytes already checked, output initialization against at most `4N` byte writes, the ICO alpha-presence scan against `N`, and packet/per-pixel/mask loops against consumed input and the remaining per-phase budget; then use `cursor<=|b|` to derive the stated `16*(|b|+N)` ceiling. Account separately for a failed two-byte command and header/constant loops. No call to `len(remaining)` may scan the remaining bytes on each packet. |
| T13 success/resource | `decode=Ok(w,h,p) iff MP=Ok(w,h,p)`; every success has `|p|=4*w*h<=67,108,864`, all cells initialized before read, each raw cell assigned once, each RLE cell painted at most once after palette-zero initialization, alpha non-premultiplied, and the cursor equals `|b|` in BareDib/ICO while BmpFile may leave a suffix after the complete raster. |

A short RLE model proof must use `variant |b|-cursor` for the command loop and a nested `q-j` for <=255 emitted pixels. Raw/AND loops use `h-r` and `w-x`. Separately establish named lemmas `stride_roundup_safe`, `row_last_sample_within_stride`, `product_width_height_bound`, `pixel_byte_offset_bound`, `vertical_flip_bijection`, `bit_mask_contiguous_extract`, `scale_round_bounds` (especially `255*c+max/2`), `palette_stride_bounds`, `rle_monotone_position`, `rle_painted_at_most_N`, and `and_bit_offset_bound`. Express nonlinear products/divisions as explicit intermediate facts; verified multiplication lemmas or `by(nonlinear_arith)` are permitted. Then compose colour, orientation, RLE and mask lemmas in T9 rather than unfolding all depths and modes in one loop proof.

Let `P=bytes(2,1,0,0)` be one two-pixel RLE8 red row plus EOL when palette entry one is red, `H_k` a 40-byte 2×k RLE8 header with two palette entries (black, red), and `E=bytes(0,1)` EOB. Use byte-string repetition only for a small, parameterised proof; the separate maximum-output fixture uses 8192×2048, a black initial palette entry, and **paints red**, so an implementation that merely returns the initial fill fails its runtime expected bytes.

- L1. For any `|b|>67,108,864`, `MP(b,mode)=Err(FileTooLarge)` in every mode; instantiate both `input-over-64m` and `precedence-too-large-bmp-bad-magic` without expanding the latter's invalid BM header.
- L2. For `b=0^67,108,864` in `BareDib`, `MP(b,mode)=Err(UnsupportedHeaderSize)` because the size word is zero and input length is **equal** to the cap. Instantiate `input-exact-64m`, killing an incorrect `>=` input guard.
- L3. For `1<=k<=16`, prove by induction on the row count that the RLE command parser after `H_k+P^j`, `0<=j<=k`, is at cursor `48+4j` and position `(0,j)` with the **last `2j` pixels in top-first output order** red (the first `2j` bottom-up source-order pixels); `E` then returns `(red)^2k`. This is a **small parameterised** packet/row proof. The separate `output-exact-64m-rle8` is a mandatory **runtime** oracle and implementation test: its input is `48+130*2048+2=266,290` bytes; its output is `8192*2048*4=67,108,864` bytes, all red rather than initially black. Prove its header/output-cap arithmetic symbolically, but do not require a 266 KiB `Seq` repetition proof or verifier-level construction of 64 MiB output. T9's universally quantified correctness is not weakened by treating this vector as runtime evidence.

## Deliberate proof-sensitivity mutations

Run each change on an isolated copy and preserve **failed verifier diagnostics** with all T1–T13 enabled. A failing fixture alone does not count. Each bullet identifies a fixture or symbolic boundary and the theorem that must reject the mutation; if an invariant accidentally reconstructs a removed check, inject an actual wrong read/write instead.

1. Change input cap `>` to `>=`: `input-exact-64m`, L2, T2/T9/T10 fail.
2. Swap planes and dimensions checks: `planes-before-dimensions`, T2/T10 fail.
3. Parse OS/2 16-byte dimensions at CORE offsets: `header-16-BareDib`, T2/T9 fail.
4. Ignore `biClrUsed` and always read the maximum palette: `palette-short-one-8`, T2/T9 fail.
5. Use a three-byte stride for INFO palette: `indexed-4-header-16`, T4/T9 fail.
6. Remove index bound before borrowed palette access: `palette-short-invalid-index-4`, T1/T4 fail.
7. Permit overlapping masks: `masks-overlap`, T2/T9 fail.
8. Replace rounded mask scaling with five-bit replication: `bi-rgb-16-630c` has each channel `c=3`, so rounded scaling gives 25 and replication gives 24; T4/T9 fail.
9. Treat BI_RGB32 alpha byte as real alpha in BmpFile/BareDib: `bi-rgb-32-11223300`, T4/T9 fail.
10. Always ignore the ICO AND mask at depth 32, including an all-zero XOR alpha plane: `ico-alpha-zero-fallback-mask`, T8/T9 fail.
11. Reverse vertical orientation: `bottom-up-two-rows`, T5/T9 fail.
12. Read only unpadded row bytes: `row-padding-24-two-pixels`, T5/T6/T9 fail.
13. Allow RLE runs to cross rows: `rle8-absolute-row-overrun-precedes-short`, T7/T10 fail.
14. Check absolute input completeness before bounds: same overrun-precedes-short witness, T7/T10 fail.
15. Check an absolute palette index before whole padded packet availability: `rle8-absolute-trunc-before-index`, T7/T10 fail.
16. Omit EOB requirement: `rle4-missing-end`, T7/T9 fail.
17. Omit full-mask guard before a mask read: `ico-truncated-and`, T1/T8 fail.
18. Compute `N=w*h` using `u16` or allocate before checking the output cap: the first has `output-exact-64m-rle8` as a runtime witness; the second is exposed by `output-before-palette`; T1/T2/T3 reject the overflow or unchecked allocation call.
19. Re-scan the entire remaining byte slice on every RLE command without changing output: T12 fails on sufficiently large repetitions of a 128-pixel run/EOL row, even if functional fixtures pass.
20. Allocate a second full-size scratch RGBA buffer: T3 fails for `output-exact-64m-rle8` despite identical output.
21. Accept arbitrary suffix bytes: `rle8-early-eob-trailing`, T9/T10 fail.
22. Ignore alpha in a 32-bit ICO pixel whose AND bit is zero: `ico-32-and-0`, T4/T9 fail.
23. Reverse AND bit order inside each byte: `ico-mask-msb-and-padding`, `ico-mask-second-byte-msb`, T8/T9 fail.
24. Reverse RLE4 high/low nibble order: `rle4-encoded`, `rle4-absolute-odd`, T7/T9 fail.
25. Ignore or invert the RLE delta offset: `rle8-delta` and `rle8-zero-delta`, T7/T9 fail.
26. Require all N pixels before EOB rather than permitting early EOB: `rle8-early-end`, T7/T9 fail.
27. Ignore the BmpFile gap and parse pixels immediately after the palette/masks: `bmp-gap-before-pixels`, `bmp-indexed-gap-4`, T6/T9 fail.
28. Allow a non-contiguous bit mask: `masks-hole`, T2/T9 fail.
29. Use 16-bit BI_RGB bit 15 as alpha: `bi-rgb-16-4404` has bit 15 clear and opaque expected alpha; T4/T9 fail.
30. Ignore `biSizeImage=X+A` at ICO depth 24: `ico-image-size-xor-and`, T8/T9/T10 fail.
31. Treat AND as a veto when some 32-bpp XOR alpha is nonzero: `ico-alpha-nonzero-ignores-and`, T8/T9 fail.
32. Clip an encoded RLE run at the right edge or accept a second EOL after the last row: `rle8-run-over-row`, `rle8-eol-past-height`, T7/T9/T10 fail.
33. Accept masks with bits beyond the pixel depth, or read a high-depth optimal table with three-byte entries: `masks-outside`, `bmp-optimal-table-two-entries-three-byte-stride`, T2/T9 fail.
