# Brief: verified ICO/CUR container core (Verus)

This project implements the frozen ICO-CORE-SPEC 1.0 (`spec-frozen/SPEC.md`, hashes in `spec-frozen/FREEZE.txt`; 217 vectors in `spec-frozen/VECTORS.json`; independent Python oracle `spec-frozen/check_vectors.py`; the oracle for the DIB half is `spec-frozen/dib_check_vectors.py`) and proves the manifest `THEOREMS.md` (T1-T11, witnesses, planned mutations) in Verus. Authority order: SPEC.md, THEOREMS.md, DESIGN-NOTES.md (owner decisions), REVIEW.md/REVIEW2.md (why). The core depends on the DIB core by path (`../dib/dib_verus`, spec 1.1, 1594 verified obligations): DIB entries are decoded by calling `dib_verus::decode_with_steps` (or `decode`) in `Mode::IcoEntryDibSlack` on EXACTLY the validated entry slice; PNG entries are returned as untouched byte ranges for the caller to delegate. Composition theorem: the ICO core's decode_entry result equals the DIB model `dib_verus::model::mp(slice, IcoEntryDibSlack)` on the validated slice, using the public contract `dib_verus::dib::decode_mp_eq`; the skeleton in `ico_verus/src/lib.rs` shows the cross-crate call verifies (1 verified, 0 errors). Do not modify `../dib` (frozen core: ask via QUESTIONS.md if something must be exported).

Binding rules (all earlier lessons: ../dib/BRIEF.md, ../dib/BRIEF-1.1.md, ../dib/BRIEF-POLICY.md, ../../reviews/REVIEW-SOL-TGA.md): every verifier run through ./verify.sh "<what>" (VERIFY_CRATE=<dir inside ico/> for copies; delete target/ and caches after: 500,000-inode volume cap); never call cargo verus verify directly; no scratch crates elsewhere; never delete or rename run logs; never edit spec-frozen/ or THEOREMS.md; no assume/admit/external_body/trusted/unsafe/todo/requires(false); no #[verifier::rlimit] or other solver-budget attribute (STUCK.md instead); state theorems at the manifest's FULL quantification (arbitrary states, exact errors and ghost state where stated); witness lemmas with projection hypotheses must be discharged from and used by the public proof; implementation mutations change ONLY ico_verus/src (executable), are faithful to the manifest's named mutant, and fail on a verifier diagnostic (not a compile/type error), audit-only kills labelled as such; per-function resource limit is the binding constraint: split functions, ghost start parameters on sub-functions, widths tied in loop invariants, named lemmas for nonlinear arithmetic, match not == on enums, parenthesise casts in comparisons. Work on branch `ico-core`; do not commit (the coordinator commits).
