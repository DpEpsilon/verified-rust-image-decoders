# ICO/CUR container core

Spec ICO-CORE-SPEC 1.0 (frozen: `spec-frozen/`, 217 vectors, independent Python oracle), manifest `THEOREMS.md`, crate `ico_verus/` (Verus; depends on the DIB core `../dib/dib_verus`, spec 1.1, `IcoEntryDibSlack` mode; DIB entries are decoded by calling `dib_verus::decode_with_steps` on exactly the validated entry slice; PNG entries are returned as byte ranges). 303 verified obligations. Proved: exact parse against an independent model, per-entry validity, PNG classification, exact total `decode_entry` including the composition with the DIB model, precedence, termination, ICO-side linear work (ghost step counter) and the combined bound as the sum of the two crates' counters, allocation-call shape (the ghost count cannot see an uncharged allocation: `tools/audit_alloc.sh` is the enforcement). Reviews: `REVIEW.md`, `REVIEW2.md` (spec), `../reviews`-style proof review `REVIEW-SOL-ICO.md` (in `../reviews/`). Mutations: logs and results under `mutation/` (source copies regenerate with `mutation/refresh_base.sh` and `tools/mutations.py`); the mutation evidence predates the final T9-sum postcondition (postcondition and comments only). 41 DIB-branch decode vectors are runtime-only by the manifest's design. Policies: this core is policy-free (Strict, DIB slack mode).
