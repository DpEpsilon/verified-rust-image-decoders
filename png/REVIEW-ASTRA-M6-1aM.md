1. **Totality does not assume decoder success.** `MS_wide` first takes the mathematical walk result, then the default IDAT raster result. Only after both succeed does it construct a record from the header, the whole `doc.info`, and the physical byte equations (`src/still_model.rs:6–48`). The walk recurs over mathematical chunk steps (`src/document_model.rs:218–254`); the raster checks inflation and length before scanning passes and rows, keeping the first error (`src/raster_model.rs:54–74,131–152`). The pixel equation maps a coordinate to its source row and colour sample (`src/paint_model.rs:9–20,66–71`). None consults the certificate, a native still decoder, or a result oracle.

   The certificate runs in the other direction. `callers::still` returns a *document or a format error*, not a decoded image. Its existing contract equates that result to the walk and excludes OOM (`src/callers.rs:10–30`). A walk error therefore already gives a model error. On walk success, `IdatReader::for_doc` identifies the exact concatenation from the same slice, and `raw_size` gives the bounded model limit (`src/reader.rs:108–118`; `src/image.rs:104–111`). M2's measuring contract relates its status to `Inflate` on that concatenation and limit. `status_eq` is false for **every** native status when the model status is `OutsideDomain`; it does not require `Done` and admits both `Full` and format errors (`../inflate_verus/src/inflate.rs:1268–1275,1362–1372`). That suffices to exclude the remaining internal branch. Neither `model_totality` nor `model_theorems` has a `requires` clause (`src/still_model.rs:184–219,462–470`). The unconditional statement covers every Rust input slice, the domain needed by 1a-E. The edges in `evidence/m6-1am-proof-map.json:300–328` match the source.

2. **No allocation premise or trust extension.** The harness creates `[u8; WINDOW_MAX]`, proves its length, and borrows it as a mutable slice; it never requests a heap reservation (`src/still_model.rs:197–207`). `WINDOW_MAX` is `1 << 15`, exactly 32,768 bytes on both targets (`../inflate_verus/src/limits.rs:8`). The pinned vstd length axiom states that `[T; N]` has length `N`; its existing unsizing wrapper returns the original borrow and preserves the view. Neither contract manufactures storage or depends on input-sized arithmetic. The diff adds no `assume`, `admit`, `external_body`, `assume_specification`, solver-limit override, or alternate implementation of an executable entry point. The only old source file touched is `src/lib.rs:58–61`, which registers the two verification modules; no old function calls them. The certificate is a checked harness, not an extra measuring pass in the shipping decoder.

3. **The byte and T13 conclusions are nonvacuous.** `image_complete` starts with the existing M5 `image_pixels` relation, which specifies the exact length and every pixel observation. It proves equality of every 4- or 8-byte block and then equality of the two sequences (`src/paint_model.rs:163–169,346–364`; `src/still_model.rs:140–166`). The unconditional coupling rejects even a pair of `OutsideDomain` results: errors must match exactly, or both records must have equal width, height, and `Info` (`src/still_model.rs:270–299,464–470`). For each narrow sample `i`, the wide sample is `256 × bytes[2i] + bytes[2i+1]`, and the narrow value is `(wide + 128) / 257` using integer division. For source depth at most eight, the wide value is exactly 257 times the narrow one (`src/still_model.rs:232–254,340–349`; `src/still_samples.rs:28–48,80–89`). These are physical adjacent bytes, as required by `../ERRATA.md:75–81`.

   On each model `Done`, `bind_model_properties` derives raster readiness **from that result**, rather than asking the caller to assume it. It ties all four channels to `value.pixels`; the resource bounds, greyscale equality, alpha cases, and indexed PLTE/tRNS lookup therefore describe the returned record (`src/still_model.rs:52–56,411–455`; `src/still_samples.rs:103–113`). In particular, the `get_Ok_0()` in the canonical byte equation does not leave reachable pixels unspecified: successful scan implies source-pixel success in both widths (`src/still_model.rs:79–95,389–405`). A pre-existing unconditional witness reaches the same success gate on a concrete 6×4 image (`src/witness_m4_filter_projection.rs:121–126,155`; `src/raster_model.rs:158–169`). This satisfies the still **model-side** clauses of `../THEOREMS.md:124`; the executable directions at lines 119, 124 and 156 remain open.
