## Named-policy equivalence

`MS_p` and `MS16_p` select the walk error first, then the raster error, otherwise dimensions, model `Info`, every physical output byte and the recovery bit (`src/policy_still_model.rs:15–45`). Raster R3 means that a reconstructed indexed sample in a real pass row is outside the palette under Black. The quantifiers stop at the pass width and height: neither row padding nor an in-range palette entry whose colour happens to be black can trigger R3 (`src/raster_model.rs:26–39`; `src/still_recovery.rs:5–10,44–52,72–80`). This matches `../policy-frozen/OPTIONS.md:17,44`. The frozen out-of-range vector gives a concrete distinction: Strict returns `PaletteIndexOutOfRange`; RecommendedBeta draws opaque black and reports exactly R3 (`../policy-frozen/VECTORS-POLICY.json:3199–3245`).

The Strict specialization agrees with the still part of P-BRIDGE at both widths. Strict projects to the same walk, uses the same raster/error calculation, and selects `still_model::image` directly. The still walk starts with no events, Strict does not take a recovering discard or frame fallback, and Reject makes the raster R3 predicate false (`src/walk_policy.rs:64–66`; `src/document_model.rs:65–71,202–254`; `src/still_model.rs:31–51`; `src/policy_still_model.rs:15–45`). This is a check of the model definitions against `../THEOREMS.md:168`, not credit for a separate universal P-BRIDGE lemma or for the later frame and ICC pairs.

The `image.rs` diff adds contracts, loop invariants and erased proof steps only. The existing out-of-range Black branch still sets the event. The pixel contract identifies exactly when it does so; the row and pass invariants carry **incoming R3 OR R3 in the processed prefix**, preserve R1/R4 and handle empty passes (`src/image.rs:817,850,902–903,935,1006–1007,1090,1139,1242–1243`). The public entries return the actual `ev.any()` from that decode. Their equality predicate compares that boolean to the mathematical result, rather than defining the mathematical result from native events (`src/png.rs:815–833,863–881`; `src/policy_still_equivalence.rs:7–32`).

For a non-OOM result, the ordinary and logged named-policy contracts require complete success equality or the identical first format error. Each logged form proves `G ∧ Prog` on the log it returns: a failed walk has no requests; after a successful walk the full request list is Raw then Output; OOM ends a nonempty prefix at its failed reservation. No still call reserves Saved, IccWindow or Icc (`src/png.rs:788–813,836–861`; `src/policy_still_equivalence.rs:34–36,74–102`). The named-model totality certificate has no input-validity or allocation-success precondition. It uses the walk, raw-size, IDAT-reader and measuring contracts with the selected inflater options and a fixed stack window. Neither the model definitions nor a production entry calls the certificate (`src/policy_still_model.rs:24–45,98–138`).
