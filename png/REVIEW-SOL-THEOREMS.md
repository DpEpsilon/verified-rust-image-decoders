# PNG theorem statement review (Sol, 2026-11-17)

Reviewer: GPT-6.1 Sol, read-only. Saved by the coordinator (the reviewer may not write files); condensed: findings, resolutions and verdict are as reported, the lists of what holds up and of checks are shortened. Subject: `png/THEOREMS.md`, `png/REVIEW-BRIEF.md`, `png/PLAN.md` against SPEC P1–P20, the oracles and the policy drafts. No PNG implementation or Verus proof was run.

## Verdict

**Not ready to freeze Stage 1 in its present form.** The draft incorporates the main GIF lessons but contains an unsatisfiable Huffman representation claim, an under-specified segmented-input contract, an inflate work bound that does not cover its segmented readers, and an unlogged disagreement between the Strict specification and its oracle on an empty fdAT payload. Stage-2-only defects need not delay Stage 1 if the freeze explicitly excludes those clauses.

## Findings

1. **High: T-HUFF part (a) requires an impossible representation for oversubscribed lengths** (`THEOREMS.md:110`, repeated by L-CANON at `:129`). For `ℓ = [1,1,1]` three symbols cannot have distinct one-bit codewords. Restrict the canonical-representation claim to `Kraft(ℓ) ≤ 2^MAX_CODE_BITS` (or to successfully constructed tables), keep the rejection/completeness comparison universal in (b), keep decoding exactness conditional on admissibility in (c), and state that oversubscribed construction is rejected before any lookup.
2. **High: T-INFL does not require a fresh cursor, and T-SEG does not preserve the input view** (`:111–112`, `:107`). A reader with the same `concat()` at `pos() = 8` returns `TruncatedZlib` where a fresh reader returns `Done([])`. Require a fresh cursor (or define the model input as the suffix at the initial cursor), preserve `concat()` across reads, specify cursor range and end behaviour and representable domains, and prove each PNG reader supplies the preconditions.
3. **High: the inflate work bound omits empty-segment traversal** (`:67`, `:112`, `:122`). One million empty segments followed by an 8-byte zlib stream cost one million skip iterations while the stated bound is 8,192 steps; one million empty IDAT chunks add only about 12 MB of container. Expose a separate segment-traversal charge (discharged in PNG from `|b|` and `Δ_n`) or return both counters; T-SEG also needs a termination/cost contract for arbitrary reader implementations. Changing `C_FIXED` cannot repair it.
4. **High: a zero-payload fdAT breaks Strict/oracle agreement and the Strict bridge** (`SPEC.md:166–168`; `png_oracle.py:459–460`, `:567–568`, `:595–596`). SPEC checks whether an fdAT-based frame has no fdAT chunk, and allows a 4-byte fdAT (sequence number, empty payload); the Strict oracle tests payload truthiness. A 180-byte 1×1 two-frame APNG with an empty-payload fdAT gives Strict still `MissingFrameData` but policy-oracle-under-Strict success; frames: constructor-level `MissingFrameData` versus frame 0 then `TruncatedZlib`. The policy oracle's `parts_seen` is correct. Track presence separately from length in the Strict oracle and the mathematical walk; add still and frames vectors, and an empty fdAT followed by non-empty fdAT data.
5. **Medium (Stage 2): policy request sizes use dimensions that become zero exactly when a policy recovers an input** (`:27`, `:91–94`, `:177`). On `policy/crc-ancillary/text/recommended-beta` Strict fails, RecommendedBeta succeeds with `Raw = 14`, `Output = 16`, but the written expression evaluates to zero. Define the common shape from the successful IHDR prefix, or use policy-indexed checked shapes; mark affected instances held out of Stage 1.
6. **Medium: the freeze procedure does not support the cap changes it says Stage 2 may make** (`REVIEW-BRIEF.md:69–75`, `:81`, `:87–92`; `THEOREMS.md:188`). A cap edit fails Stage 1's `sha256sum -c`; setting `MAX_DIMENSION = 1` turns `container/minimal-ok` into `InvalidDimensions`. Separate immutable baseline reproducibility from the future choice of cap values (explicit cap premises on fixtures, a permitted fixture envelope, or an append-only Stage-2 delta).
7. **Medium: one named M2 witness has an empty extraction domain** (`THEOREMS.md:190–192`; `check_vectors.py:94–113`). On `zlib/empty-idat-only` the extractor returns `[]`. Distinguish an existing empty IDAT run from no IDAT run; apply the same to empty fdAT payloads.
8. **Low: L-HDR-BITS has a true lower bound but a false supporting assertion** (`:134`): a valid dynamic header can use one-bit code-length symbols throughout (329 bits). The 45-bit lower bound survives via an aggregate coding-cost argument.
9. **Low: the policy validation evidence does not cover the full Info equality claimed** (`:167–170`; `validate.py:152–155`, `:162–173`; `policy_oracle.py:749`). Describe the Python evidence as the pixel/recovered comparison it is; add the missing observations or model lemmas.

## What holds up (reviewer's list, shortened)

The independent inflate-model design (canonical codewords, independently appended output, L-CANON/L-WINDOW/L-RING as bridges) is better than GIF's original shared representation; the non-OOM antecedents in T9, T10, T13, P-T9 and P-BRIDGE are correctly placed; A-PNG-4's sealed-log clauses and the Saved observable-content clause are sound; the five allocation sites suffice and A-PNG-3's per-reservation bounds fit the 1 GiB guard (the 1.125 GiB figure is an upper bound on aggregate live heap, not an attained maximum; the exact 1×2^26 RGBA16 shape gives Raw 576 MiB and 1,088 MiB with 8N); add `WINDOW_MAX ≤ MAX_BYTES` to the allocation facts; the work constants are credible apart from the segment-cost defect; the summed iterator inequality is arithmetically sound once reader costs are accounted for.

## Checks and limits

All Python experiments ran under `python3 -I -B` with bounded timeouts; no repository file edited. Recomputed all 796 vectors (796 agree); the cap-sensitive set is 12 Strict and 6 profile records (blind doubling of `MAX_DIMENSION` above the wire maximum adds a thirteenth, `ihdr/width-2^31`, which violates `caps_ok` and is not a permitted change: state the perturbation domain); 586 Strict records exercise 57 of 62 errors; 1,163 vector streams plus 200 random and 200 corrupted agree with zlib (three declared window rule differences); `check_bounds.py` passes; 1,089 small Adam7 bijections and 49 large exact pass-area sums; all 65,536 16-bit rounding inputs; filters for all five types and distances 1,2,3,4,6,8; OVER over all 65,536 alpha pairs; Kraft against exact sums on 5,461 small length vectors; `validate.py --no-large`: 773 and 372 pass. Not verified: Verus, compiling the crates, mutation tests, incumbent binaries, `check_over.py`'s full 4.26-billion-tuple run, the real corpus pass, fault injection, the production audit, any freeze command. A focused re-review should check the corrected Huffman domains, the full Segments contract and accounting boundary, the new empty-fdAT vectors, the chosen error/prefix rules and the revised cap-independent freeze procedure before Stage 1 is declared ready.
