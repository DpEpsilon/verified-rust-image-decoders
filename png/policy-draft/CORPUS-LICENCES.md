## Corrections to BRIEF.md's licence column

- **libpng `contrib/pngsuite`** is not "PNG Reference Library License v2". It is Willem van Schaik's freeware grant (README: "Permission to use, copy, modify, and distribute these images for any purpose and without fee"), plus two files by Glenn Randers-Pehrson under the same README. Only `contrib/testpngs` falls under `libpng-2.0`, and then only by repo default (the 33 files in `badpal/`, `crashers/` and `png-3/` have no provenance note).
- **image-png `tests/`** is not uniformly "MIT OR Apache-2.0": `tests/pngsuite/` is the PngSuite freeware grant; `tests/bugfixes/gama-srgb-order-issue#304.png` is CC-BY-2.0; `tests/benches/` includes two CC-BY-SA-3.0 files and Kodak "unrestricted use" images; `tests/bugfixes/` is mostly PngSuite-derived by `License.toml`'s own comment. The other files have no per-file provenance. "0.18.1" has no git tag upstream; use commit `2a3f980245e3ae38b82ade96533e7b450e8477bb`. All licence-bearing test files are identical at that commit and at `e917d6a`.
- **Wuffs** is "Apache-2.0 OR MIT" (dual since 2023-10-05), not "Apache-2.0", and its `test/data/README.md` lists third-party exceptions (notably `ridiculously-fast.png`, a tweet screenshot with no licence). Wuffs does not vendor PngSuite or the Blink suite.
- **APNG, first source**: the author is Philip Taylor (`philip.html5.org/tests/apng/`), not Philip Jägenstedt, per the WPT README. The original page is unreachable, so its licence stays UNVERIFIED. The WPT port (`web-platform-tests/wpt`, `png/apng/`) has a generator under MIT ("Copyright (c) 2007 Philip Taylor") in a BSD-3-Clause repository; use it as the collection source.
- **Chromium** "BSD-3-Clause" holds only as the repository default. No statement covers `web_tests/images/resources/`, and the APNG files' origin is not recorded.
- **Mozilla** "MPL-2.0" is confirmed only as the tree default (via `LICENSE` to `license.html`), with no per-file statement. Use `mozilla-firefox/firefox`; `mozilla/gecko-dev` is archived.
- **gdk-pixbuf** "LGPL-2.1-or-later" is confirmed as repo default; the PNGs are also in `tests/` itself, not only `tests/test-images/`.
- **Real-world row**: Adwaita is `LGPL-3.0-only OR CC-BY-SA-3.0-US` (a ShareAlike or LGPL obligation on any redistributed copy); the hicolor theme package contains no PNGs.
