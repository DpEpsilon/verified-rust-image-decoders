# TGA core theorem manifest (frozen)

This manifest applies to TGA-CORE-SPEC 1.0 (`spec-frozen/SPEC.md`, R1–R17) and is proportioned for one Verus implementer. The notation is mathematical, not mandated Verus syntax. The proof model must be written independently of executable parsing and decoding; testing the executable against the vectors does not prove the model.

## Total reference models

`Result<X> = Ok(X) | Err(e)`, where `e` is exactly one of R15's 18 errors. The model uses mathematical integers for lengths and offsets; concrete calls use Rust slices and therefore `|b|<=isize::MAX`, with the proof checked for both 32-bit and 64-bit `usize` targets (or parameterized by a word width `W` in `{32,64}` and justified for each). `OutsideDomain` is an internal proof marker, **not** a nineteenth error. `LE16(b,p)` is defined only after checking that both bytes exist. A result has exact `u32` width/height and exact `4*width*height` RGBA bytes.

`MH(b)` is the total ordered header-and-resource model. Check R1 input cap and 18-byte header first; test type, flag, dimensions, interleave, image depth, map coherence/depth, map range, attribute count and output cap in R14 order. On success it returns a record containing the exact raw header fields, `N`, `sample_bytes` and `map_bytes`; all sizes are computed in natural numbers before narrowing. No absent byte is read. It returns `Err` at the first check failure. This is an independent model of checks, not a call to the implementation's header parser.

`MP(b)` is the complete **total** decoder model. Call `MH`; propagate its error. Test and skip the image ID; check and slice the map; apply R8's exact word/channel/alpha conversion. For raw images test each complete sample before decoding; for RLE images use one cursor and a produced count, checking control presence, overrun, whole-packet bytes, then each sample index in that order. Write each decoded pixel to the R9 oriented output position. Check R12's footer/suffix rule only after pixel `N`. Every error returns immediately. The model's pixel result contains every byte, not just output dimensions. Define `Accepted(b) iff exists w,h,p: MP(b)=Ok(w,h,p)`.

`MR(s,H,map,cursor0,produced0)` is a total packet model: `s` is the finite entire byte stream, `H` is a successful `MH` header record including image depth, descriptor attribute count, map entry depth, `N`, sample width, map `first`/`length` and map-byte count; `map` is the checked map slice; `cursor0` is the absolute cursor just after ID and map; `produced0` is the number of already produced pixels. Its success is `Ok(cursor',produced',pixels)`, where `pixels` is the ordered sequence of **converted RGBA8 pixels produced since `produced0`**, without orientation; its failure is `Err(e,cursor',produced',pixels)`, carrying the first error (`RleTruncated`, `RleOverrun`, or `ColorIndexOutOfRange`) and the ghost state at that check. These state fields are proof observations, not additional public API result fields. For reachable calls `0<=produced0<=N` and `0<=cursor0<=|s|`, each repeat/literal packet enforces `count<=N-produced` before reading packet data, validates the whole encoded packet before its first palette lookup, then converts using the indexed or true-colour/grey depth and attribute policy in `H`. The concrete helper is compared at exactly the same starting cursor and produced count. Mathematical calls on other records/offsets remain total by returning `OutsideDomain` (not an API error); `MP` models raw samples, orientation and the post-pixel suffix test independently, and may call this mathematical `MR` but never executable RLE code.

`Safe(f,args)` means the concrete function terminates without panic, unchecked integer overflow/narrowing, out-of-bounds read/write, recursion dependent on input length or unbounded allocation requests, assuming requested allocations succeed and an ordinary process stack exists. This does not turn an out-of-memory abort into a format error. No proof may assume a valid header, valid packet, valid index or a length cap as a premise for a **public** decode call. The parser's successful-header invariants are proved from concrete code and transported to the pixel decoder, not inserted as axioms.

## Required obligations

| ID | Exact quantified claim | Excluded shortcut |
| --- | --- | --- |
| T1 · safety | `forall b` representable as a Rust slice on either 32-bit or 64-bit targets (`|b|<=isize::MAX` for that target): `Safe(decode,b)`. Prove input-cap rejection before input-dependent allocation; every read/index/narrow is guarded; successful RGBA allocation requests exactly `4*N<=67,108,864`. | Assuming input under the cap, header complete or any valid image type. |
| T2 · header safety | `forall b` representable as a Rust slice on either target: `Safe(parse_header,b)` for the actual header routine, if separate; on success its width/height are 1..8,192, `N<=16,777,216`, map-byte count <=262,140, and computed positions fit the input when used. If header logic is inline, prove this as a named decoder invariant. | Postulating checked widths or valid ranges. |
| T3 · packet safety/termination | For every successful concrete header/map prefix and every remaining finite stream `s`, the actual RLE helper terminates without invalid access on all 0..255 controls and requests no pixel buffer beyond `4*N`; the loop variant `N-produced` strictly decreases or returns an error. | Assuming packet bytes exist, run counts fit or samples are in the palette. |
| T4 · conversion/orientation bounds | For each concrete accepted header and every `k<N`, sample conversion reads at most its validated 1..4 sample bytes and a validated map entry; `4*(Y*width+X)+4<=4*N`; the map access lies within its checked slice. Distinct `k` write distinct output positions. | Assuming top-left origin or a zero map first index. |
| T5 · exact header semantics | `forall b` representable as a Rust slice on either target: `parse_header(b)=MH(b)` as exact success record or exact first error; if inline, the proved header-prefix transition of `decode` equals `MH`. | Proving accepted inputs only or reducing all header errors to one. |
| T6 · exact packet semantics | For each reachable successful `MH` header/map prefix and every finite stream continuation at a valid starting `(cursor0,produced0)`, the concrete RLE helper result equals `MR(s,H,map,cursor0,produced0)` exactly, including the converted ordered RGBA pixels, final cursor and final produced count on success, and the exact first error with ghost cursor/produced state on failure; no restriction to valid packets. | Comparing only produced count or only successful streams. |
| T7 · total functional correctness | `forall b` representable as a Rust slice on either target: `decode(b)=MP(b)` as exact `Result`, including all output bytes, both flips, alpha, map offsets, footer behavior and first error. | Restricting to vector inputs or using executable code as the model. |
| T8 · success and resource bounds | `forall b: decode(b)=Ok(w,h,p) iff MP(b)=Ok(w,h,p)`; in either direction `1<=w,h<=8192`, `|p|=4*w*h<=67,108,864`, and every `p[4i..4i+4]` equals R8's non-premultiplied sample at R9's unique oriented position. | Proving only dimensions/length or a one-way implication. |
| T9 · precedence | `forall b: decode(b)=Err(e) iff MP(b)=Err(e)` for each R15 error, with the header check order and RLE control/overrun/full-packet/index order explicit; then `decode` returns neither pixels nor a second error. | Assuming a single defect or swapping an overrun for a truncation. |
| T10 · termination | For all representable inputs, the header consumes a fixed 18-byte prefix or returns, ID/map checks are finite, raw decoding increments sample index by one, RLE decoding increments produced by 1..128, and output writes perform no input-dependent recursion. | Inferring totality only from a successful fixed vector. |
| T11 · integrated call path | From a **concrete** `decode(b)` call, prove every header-success invariant used by RLE, palette, orientation and footer functions, then derive T7–T9 without assuming a forged header or switching byte slices. | A model equivalence stated only for an impossible precondition. |

T1–T4/T10 cover safety and termination; T5–T9/T11 cover exact behavior, bounds and precedence. A single combined lemma can discharge multiple rows, but the report identifies each row's proved statement. No `assume`, `admit`, `external_body`, trusted wrapper, unverified FFI, unsafe operation or vacuous false precondition may establish an obligation. State verifier, standard-library contract and compiler versions. Allocator failure, process termination and verifier/compiler unsoundness remain outside the claim.

Before T4/T7, prove a separate **orientation-map bijection lemma**: for every `1<=w,h<=8192`, `N=w*h`, and either setting of each origin bit, `f(k)=Y(k)*w+X(k)` maps `[0,N)` bijectively onto `[0,N)`. Prove `0<=f(k)<N`, injectivity (`f(j)=f(k) -> j=k`) and surjectivity (`forall q<N, exists! k<N: f(k)=q`), using quotient/remainder and each axis's involutive flip; then checked `4*f(k)+4<=4*N` follows from `4*N<=MAX_OUTPUT`. T4/T7 use injectivity for the loop invariant `forall j<produced: out[4*f(j)..4*f(j)+4]=conv(sample(j))`; L3/L4 use surjectivity to establish that every cell is written. State each nonlinear fact needed for bounds, injectivity and surjectivity as a named lemma; those lemmas may use `by(nonlinear_arith)` or verified multiplication lemmas.

Prove **colour conversion separately** as a `conv(header, sample, map)` lemma for all supported true-colour/greyscale depths and indexed entry depths, including R8 bit replication, attribute policies and validated map slices. Compose its byte-exact result with the raw/RLE loop and orientation bijection in T7/T11 rather than expanding six image types, four orientations and all colour depths in one loop proof.

Prove a **packet repetition lemma** by induction on `k>=0`: given a reachable header and map, `N-produced0=128*k`, a valid starting cursor `cursor0`, and a control/sample packet `P` of length `1+sample_bytes` with control `0xff` whose complete sample converts to colour `c`, `MR(prefix+P^k,H,map,cursor0,produced0)=Ok(cursor0+k*|P|,N,c^(128*k))`, where `prefix` has length `cursor0` and supplies the checked header/ID/map. The base case has `produced0=N` and no packet read; the step uses `count=128` and remaining pixels `>=128`. State MP's orientation consequence using the bijection, then instantiate with `produced0=0` once for each of L3/L4; their fixed packet samples and exact input sizes are arithmetic corollaries, not separate 131,072-step evaluations.

## Deliberate proof-sensitivity mutations

Run each mutation in a disposable copy; restore it before the next. Keep failed **verifier** diagnostics with all T1–T11 enabled. A failed runtime test alone is insufficient. If a removed postcondition is reconstructed by another lemma, inject an actual incorrect sample/write instead.

1. Replace `|b|>MAX_INPUT` with `>=`; L2 and T7/T9 must fail.
2. Swap the image-type and map-flag checks; `type-before-flag-and-dimensions` and T5/T9 must fail.
3. Remove the dimension cap; `dimensions-8193-1` and T5/T8 must fail.
4. Ignore colour-map `first`; `palette-first-65535` and T7 must fail.
5. Use `v&0x8000` as alpha even for attribute count zero; `raw-16-opaque-bit-off` and T7 must fail.
6. Change repeat count from `(control&127)+1` to `control&127`; `rle-true-repeat` and T3/T6/T7/T10 must fail (control `0x80` otherwise makes no progress).
7. Check packet availability before packet overrun; `rle-repeat-overrun-no-sample` and T6/T9 must fail.
8. Reset the RLE produced count at each row; `rle-crosses-row` and T6/T7 must fail.
9. Reverse the vertical flip; `origin-bottom-left` and T7/T8 must fail.
10. Accept arbitrary suffix bytes without a footer; `trailing-one-byte` and T7/T9 must fail.
11. Dereference a footer offset instead of treating it as opaque; `footer-opaque-offsets` and T1/T7 must fail (on any unguarded out-of-range read, T1 even if the runtime aborts before producing a pixel).
12. Replace bit replication `(c<<3)|(c>>2)` by rounded scaling `(c*255+15)/31`; `raw-15-mixed-0c63`, `raw-16-mixed-0444`, `palette-15-mixed-0c63`, and the conversion lemma/T7 must fail.
13. Start a map at byte 18 rather than `18+ID_length`; `indexed-map-after-id-3` or `indexed-map-after-id-255`, plus T4/T7, must fail.
14. Use a fixed three-byte map stride; `palette-16-index-6-type-9` and `palette-32-index-6-type-9`, plus T4/T7, must fail.
15. Remove the whole-literal availability guard before reading a literal packet; `rle-literal-missing-sample`, T3 and T1 must fail by an out-of-bounds-read obligation, even when the runtime aborts rather than returning `RleTruncated`.
16. Compute `N=width*height` in `u16` without checking or widening; the verifier must reject the mutant through T1/T2/T8 because valid headers with `N>65,535` overflow `u16`. The large `output-at-64m-8192x2048` fixture is a possible runtime witness, not a replacement for failed verifier obligations. Computing `4*N` in `u32` alone is not an overflow mutant under R2: even `4*8192*8192=268,435,456` fits `u32`; the review's suggested `u32` example cannot demonstrate an overflow.
17. Remove the palette range guard before indexing: `index-below-first`, T4 and T1 must fail, including an OOB read or subtraction underflow on the 32-bit target.
18. Use the stored A byte even when 32-bit true-colour attribute count is zero; `raw-32-alpha-zero-ignores-byte`, the conversion lemma and T7 must fail.
19. Use the stored second byte of 16-bit greyscale when attribute count is zero; `gray16-alpha-zero`, the conversion lemma and T7 must fail.
20. Treat bit 15 clear as transparent for 16-bit true-colour count one; `raw-16-alpha-zero`, the conversion lemma and T7 must fail.
