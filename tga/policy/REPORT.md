# TGA policy candidate: report

Status: frozen candidate, not frozen. 13 internal fields, 4 named profiles (Strict = shipped TGA-CORE-SPEC 1.0, Recommended = Strict plus four error-site relaxations, GdkCompat-2.42.12, ImageCrateCompat-0.25.10). `policy_oracle.py` passes all 169 frozen vectors under Strict and every vector in `POLICY-VECTORS.json`. Everything below this paragraph is regenerated by `python3 -I validate.py` (after `investigate_pixdiff.py`); native results are cached under `/tmp/claude-0/tga-policy/`.

## Measured agreement

Columns: all-input agreement (accept/reject, and identical width/height/RGBA SHA-256 when both accept) | exact pixels among inputs the native decoder accepts | both reject | residual classes. Error names are not compared: when the oracle rejects, validate.py counts any native rejection as agreement (`same = ours[:1] == theirs[:1]`), so a both-reject row says nothing about the first error. `verified` is the shipped Verus core, so the Strict row checks the oracle against the implementation.

Only the seed-4242 run is independent validation: its 1,465 inputs were generated after the final spec edit and run once, and each named profile agrees with its native target on 1465/1465. The corpus, the synthetic vectors and the tuned seeds (20261111, 777) were inspected while the spec was written, so their agreement figures are regression checks, not evidence of generalisation. All mutation sets come from the same generator. glycin's image-rs path and image 0.25.10, and the two GDK entry points, are not independent votes.
